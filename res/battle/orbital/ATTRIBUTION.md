# Lunar texture attribution

The lunar color and elevation maps in this directory come from NASA's Scientific Visualization Studio CGI Moon Kit:

- Source: https://svs.gsfc.nasa.gov/4720/
- Color: `lroc_color_2k.jpg`, derived from the Lunar Reconnaissance Orbiter Camera WAC mosaic
- Height: `ldem_3_8bit.jpg`, derived from Lunar Orbiter Laser Altimeter elevation data
- Credit: NASA's Scientific Visualization Studio; Ernie Wright (USRA); Noah Petro (NASA/GSFC)

The files are stored locally so the battle center does not depend on a runtime network request.
